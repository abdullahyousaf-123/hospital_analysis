# 🏥 Hospital Patient & Treatment Analysis (SQL Project)

## 📌 Project Overview

This is a **real-world SQL data analysis project** based on a hospital management system.  
The goal of this project is to analyze hospital operations such as patient admissions, doctor performance, disease trends, treatment costs, and overall revenue.

This project demonstrates **SQL skills used in real data analyst jobs**, including joins, aggregations, and business insights.

---

## 🎯 Objectives

- Analyze patient admission data
- Identify most common diseases
- Evaluate doctor performance
- Calculate treatment costs and hospital revenue
- Measure patient stay duration
- Generate city-wise patient insights

---

## 🗄️ Database Structure

The project consists of 4 main tables:

### 1. Patients Table
Stores patient personal information.

### 2. Doctors Table
Contains doctor details and specialization.

### 3. Admissions Table
Tracks patient admissions, diseases, and assigned doctors.

### 4. Treatments Table
Stores treatment details and associated costs.

---

## 🏗️ ER Relationship Overview

- One patient can have multiple admissions  
- One doctor can treat multiple patients  
- Each admission can have multiple treatments  

---

## 📊 Key SQL Analysis Performed

### 💰 Total Hospital Revenue
Calculated total revenue generated from treatments.

### 🦠 Most Common Diseases
Identified diseases with the highest number of cases.

### 👨‍⚕️ Top Performing Doctors
Ranked doctors based on number of treated patients.

### 💊 Average Treatment Cost per Disease
Analyzed cost distribution across diseases.

### ⏳ Patient Stay Duration
Measured hospital stay time for each patient.

### 🏙️ City-wise Patient Distribution
Analyzed patient count across different cities.

---

## 🧠 Sample Insights

- Which diseases are most frequent in the hospital
- Which doctor handles the most patients
- Which treatments generate the highest cost
- Which patients stay longer in hospital
- Which cities have higher patient admission rates
